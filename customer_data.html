Customer Segmentation for a Digital Banking App

Overview

I built a customer segmentation framework from 3 years of transaction data for a digital banking app (Yapeal). The goal was to turn raw transaction logs into actionable customer segments that product and marketing teams can use for personalization and CLV growth. The pipeline: feature engineering → preprocessing → PCA → K-means++ → evaluation → interpretation.

What I delivered:

  • 5 behavioral segments based on customer-level RFM+ features
  • Stakeholder-ready segment definitions (plain-language summaries + visuals)
  • Action guidance (what to do with each segment: retention / upsell / reactivation)

GitHub

My role

I owned the analytical core of this project : from feature design and clustering decisions to segment interpretation, ensuring the output was both statistically sound and usable for business teams.

  • Feature engineering: designed customer-level aggregation
  • Preprocessing: stabilized skewed transaction variables via log transforms + scaling for distance-based clustering
  • PCA: reduced redundancy/multicollinearity to improve cluster separability and interpretability
  • Clustering: implemented K-means++ and selected K using Elbow + Silhouette trade-offs
  • Interpretation: created segment definitions and analytical visuals to support stakeholder understanding

What is the business impact?

  • Personalization foundation: replaced “average user” assumptions with segment-level behavior patterns
  • Growth levers: clarified which users to retain, which to upsell, and which to reactivate
  • Operational usability: delivered interpretable segments and visuals that non-technical teams can act on

Solution

Problem 1 : Customers were treated as one “average user”

User behavior differed significantly across customers, but strategy lacked a clear segmentation model. This limited targeted engagement and CLV growth.

💡 Solution: I engineered customer-level RFM+ behavioral features and segmented users with PCA + K-means++ into five distinct clusters.

Problem 2 : Statistically valid clusters were hard to interpret

Clusters can be mathematically “good” but still fail if stakeholders cannot understand what each segment represents.

💡 Solution: I characterized clusters using spending scale, frequency, recency, and category patterns, then created clear segment summaries and visuals to make them decision-ready.

Problem 3 : Insights didn’t translate into clear actions

Even strong segmentation is wasted unless it informs concrete engagement strategies and prioritization.

💡 Solution: I supported an action mapping for each segment (retention / upsell / reactivation) so the segmentation can be operationalized in campaigns and product decisions.
